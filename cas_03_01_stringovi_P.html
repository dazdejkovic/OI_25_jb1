Stringovi

Stringovi su naredna klasa podataka u Python-u koja se koristi za unošenje tekstualnih informacija. Da bismo nekoj promenljivoj dodelili string koristimo jednostruke (’…’) ili dvostruke navodnike (”…”) sa istim rezultatom

x = 'Dobar dan'

y = "Pozdrav svima"

print(type(x))
type(x)

<class 'str'>

str

Postoji i treći način:

z = '''

Pored komentara, ovako možemo definisati i stringove

Ovo je najlakša opcija kada nam treba string u više redova.

'''
# primetite sada razliku u autputu ova dva ispisa ovog stringa
print(z)
z

Pored komentara, ovako možemo definisati i stringove

Ovo je najlakša opcija kada nam treba string u više redova.

'\n\nPored komentara, ovako možemo definisati i stringove\n\nOvo je najlakša opcija kada nam treba string u više redova.\n\n'

  • Novi red, označen kao \n jedan je od tzv. izlaznih sekvenci (escape character)

  • One služe da daju naredbe nekih specifičnih karaktera (kao što je novi red)

  • Pored \n imamo i \t (za TAB) ili \\ za kosu crtu

  • Više detalja možete naći OVDE

Čemu tri različita načina za unošenje stringova? Razlog je jednostavan, često nam kao sastavni deo stringa treba neki od navodnika, te na ovaj način olakšavamo unos specifičnih rečenica. Pokušajte i sami, recimo naredne rečenice da unesete kao string:

  • „Yes”, they said.

  • That was Peter’s book.

  • What do you do? „He doesn’t know”, she replied.

Još jedna opcija je i da iskoristite obrnutu kosu crtu (eng. backslash) \ pre apostrofa

string1 = "That was Peter's book."
string1

"That was Peter's book."

Naravno, postoji uvek više načina kako da ispravno napišemo isti string.

string2 = "That was Peter's book."
string2

"That was Peter's book."

string3 = 'That was Peter\'s book.'
string3 

"That was Peter's book."

Još jedan napredni 🐍 🐍 🐍 komentar:

Ako ne želite da karakteri koji počinju sa \ budu interpretirani kao specijalni karakteri, možete koristiti raw strings tako što ćete dodati jedno slovo r pre prvih navodnika.

Ovo je korisno ako imate veći broj specijalnih karaktera unutar stringa.

print('C:\some\name')  # ovde \n znači nova linija
print(r'C:\some\name')  # primetite r pre navodnika

Indeksiranje stringova

Svakom karakteru stringa pristupamo vrlo jednostavno. Stringovi su indeksirani, tako što prvi karakter ima indeks 0.

s = 'Jedan kratak niz'
s[1] # karakter na poziciji 2

'e'

Indeksi mogu biti i negativni brojevi, kada brojanje počinje sa desne strane

s[-1]  #Poslednji karakter

'z'

s[-6] #šesti karakter sdesna

'a'

Naravno, ako pokušamo da pristupimo nepostojećem indeksu, Python interpreter će prijaviti grešku

Isecanje (engl. slicing)

Dok se indeksiranje koristi kako bi izdvojili pojedinačni karakter, isecanje (često se kaže i slajsing) nam omogućava da dobijemo podstring. Izuzetno važan način koji ćemo takođe nadalje koristiti često.

word = "Python"
word[0:2] # karakteri od pozicije 0 (uključujući) do pozicije 2 (isključujući)

'Py'

word[2:5] # karakteri od pozicije 2 (uključujući) do pozicije 5 (isključujući)

'tho'

word[2:-2]

'th'

Ne moramo navoditi obe vrednosti unutar uglastih zagrada. U tom slučaju sugerišemo da se krene od starta ili da se ide do kraja stringa:

word[:3] #Kreni od starta do karaktera sa indeksom 3 (isključujući njega)
# word[:3] je isto sto i word[0:3]

'Pyt'

word[3:] # Počevši od karaktera sa indeksom 3 ispiši mi string do kraja

'hon'

Vreme je za kviz

#Python
word[-2:]

# a - Pytho
# b - on
# c - ohtyP

'on'

#Python
word[-2:-4]

# a - th
# b - ''
# c - Error

''

# word = Python

# c - :
# d - ""

Operacije sa stringovima

Operatori + i * mogu se koristiti i kod stringova, sa malo drugačijom namenom:

  • + - spaja dva stringa u jedan

  • * - ponavlja vrednost stringa određeni broj puta

  • += takođe je i dalje aktivna

Razmislite šta će biti vrednost stringa s1 kreiranog sledećom linijom koda:

s1 = 3 * 'py' + 'thon'

s1 = 3 * "py" + 'thon'
s2 = 'py' + 'thon' * 2 # Primetite kako prioritet operacija i dalje postoji
print(s1)
print(s2)

pypypython
pythonthon

Spajanje stringova neće kreirati razmak između karaktera. Razmake možemo uvesti kao zaseban string:

s2 = 'py' + ' ' + 'py' + " " + 'thon'
print(s2)

py py thon

Nepromenljivost stringova

Jedna od važnih osobina stringa je njegova nepromenljivost (eng. immutable object). Dodeljivanje nove vrednosti nekom elementu stringa nije dozvoljeno.

word[0] = 'J'

---------------------------------------------------------------------------

----> 1 word[0] = 'J'

TypeError: 'str' object does not support item assignment

word[2:] = 'py'

---------------------------------------------------------------------------
TypeError                                 Traceback (most recent call last)
Cell In[28], line 1
----> 1 word[2:] = 'py'

TypeError: 'str' object does not support item assignment

Svaki drugačiji string moramo iznova kreirati (bilo unutar neke promenljive ili ne)

'J' + word[1:]

'Jython'
